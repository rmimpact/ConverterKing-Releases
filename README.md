# ConverterKing

Official signed and notarized downloads for ConverterKing, a private on-device media converter for Apple silicon Macs.

## Download

[Download the latest ConverterKing DMG](https://github.com/rmimpact/ConverterKing-Releases/releases/latest/download/ConverterKing.dmg)

Requires macOS 14 or later on an Apple silicon Mac.

ConverterKing checks this repository's signed Sparkle feed for updates. Release archives are verified cryptographically before installation.
